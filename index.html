My HandPong Game

HandPong is an interactive way to play Pong using real-time hand tracking. The application combines computer vision and gesture recognition so you can control the game with your hands in a futuristic gameplay experience.
The game is a modern interpretation of the classic Pong game, where the player controls a paddle using hand tracking instead of traditional keyboard controls. By moving their hand in front of the webcam, the player can move the paddle vertically to hit the ball back towards the opponent’s side. Each successful hit increases the player’s score by one point. The ball gradually increases in speed over time, making the game more challenging as the player must react faster. The game ends when the player misses the ball and it reaches the back of the field.

Technology

OpenCV Computer Vision

OpenCV processes the live camera feed and helps the game understand movement, frames, and visual input in real time.

Mediapipe Hand Tracking

Mediapipe detects hand landmarks with speed and precision, allowing the paddle to respond naturally to player hand movements.

Python

Python powers the game logic, integrates the hand-tracking systems, and connects score data to the leaderboard database.
